## 🔭 Project Overview

This tool automates the extraction and detection of pollen grains from massive microscopy files. It is designed to handle multi-gigabyte `.czi` files by breaking them into manageable, high-resolution overlapping tiles for inference and training.

- **Input:** High-resolution microscopy scans (`.czi`).
- **Output:** Annotated segmentation datasets, YOLOv8 model weights, and performance reports.
- **Goal:** Enable rapid active learning loops where unseen species (e.g., `Ran_adu`) are continuously extracted, pseudo-labeled, and fed back into Roboflow to improve the generalized model.

---

## 🔬 Methodology

The project runs on the **CESNET MetaCentrum** high-performance computing cluster, using Kubernetes Jobs to orchestrate data ingestion, training, and inference.

### Key Strategies:
1. **High-Res CZI Tiling:** Large `.czi` files are systematically dissected into overlapping 640x640 pixel tiles (`src/czi_ingest.py` & `src/extract_300.py`). This preserves the necessary morphological texture of the pollen.
2. **Unified Class Segmentation:** Regardless of the biological species, the model unifies all detections into a single `0: pollen` class. Initial bounding-box detections are mathematically converted into 4-point polygon masks (`src/pseudo_label.py`) to serve as seamless Roboflow segmentation annotations.
3. **Active Learning Loop:** Unseen data is automatically pulled from the S3 storage bucket, subjected to YOLO inference to generate pseudo-labels, and zipped for immediate Roboflow validation.

## ⚙️ Workflow Setup (CESNET)

Deployment is managed via targeted Kubernetes Jobs running in the `stenc-ns` namespace. All data is securely synchronized back and forth with S3 storage (`https://s3.cl4.du.cesnet.cz`).

### S3 Storage Architecture
- **Raw Data:** `s3://$S3_BUCKET/PEG/Colorado/Source/`
- **Staging Areas (Datasets):** `s3://$S3_BUCKET/PEG/Colorado/staging_area/`
- **Model Weights:** `s3://$S3_BUCKET/PEG/Colorado/trained_models/`

### Kubernetes Initialization
Deployment scripts (like `deploy_czi.sh` or `apply_ran_adu.sh`) will automatically locate your `kubeconfig.yaml` and `kubectl` binaries to deploy workflows seamlessly on CESNET.

## 🏷️ Labeling Guide (Roboflow)

We use **Roboflow** for semantic annotation and dataset versioning. 

### Core Rules:
1. **Single Class (`pollen`):** All pollen objects must be labeled as the single, unified class `pollen` (Class ID `0`).
2. **Polygon Masks:** Draw tight, precise polygons around the perimeter of the pollen grain. Do not use standard bounding boxes.
3. **Ghosting/Debris:** Ensure that background artifacts, air bubbles, and non-pollen debris are explicitly ignored to reduce false positives.
4. **Imports:** You can drag and drop the `_pseudo_labels.zip` packages generated by the pipeline straight into Roboflow—they are natively pre-formatted with polygon coordinates!

## 🏋️ Training Pipeline

Training is fully automated and dispatched to GPU nodes on the CESNET cluster.

**Workflow:**
1. **Job Dispatch:** `kubectl apply -f k8s/pollen-train-job.yaml` (or `k8s/pollen-general-train-job.yaml`) connects to S3 and pulls the latest unified dataset.
2. **Process:** The script trains a fresh YOLOv8 model for 100+ epochs using the configured hyperparameters.
3. **Output:** Once finished, optimal weights (`best.pt`) and evaluation matrices are forcefully synced back to the S3 `trained_models/` directory.
4. **Notification:** A Python script (`notify_on_completion.py`) intercepts the end sequence and emails the results directly to the researchers.

## 🔍 Extraction & Pseudo-Labeling

To enrich the Roboflow dataset with new, diverse microscopic imagery without starting from scratch:

**1. Extract Unseen Tiles**
The pipeline selectively downloads unused `.czi` species files and extracts targeted overlapping 640px tiles.
```bash
# Example Job:
kubectl apply -f k8s/pollen-extract-ran-adu-job.yaml
```

**2. Generate Pseudo-Labels**
Uses the most recent best-performing YOLO weights to predict pollen locations on the *unseen* datasets, mapped to segmentation polygons via `pseudo_label.py`.
```bash
kubectl apply -f k8s/pollen-pseudo-label-ran-adu-job.yaml
```
Output: `dataset_pseudo_labels.zip` ready for Roboflow validation.
